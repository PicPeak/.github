# Getting help with PicPeak

Thanks for using PicPeak! Here's the fastest way to get what you need.

## 📚 Start with the docs

Most setup and configuration questions are answered in the documentation:

- **Documentation:** https://docs.picpeak.app
- **Homepage:** https://www.picpeak.app
- **Live demo:** https://demo.picpeak.app

## 💬 Questions & discussion

For "how do I...", ideas, or general discussion, use
[GitHub Discussions](https://github.com/PicPeak/picpeak/discussions) rather than
opening an issue. It keeps answers searchable for the next person.

## 🐛 Bugs & feature requests

- **Bug?** [Open a bug report](https://github.com/PicPeak/picpeak/issues/new?template=bug_report.md) — include your version, deployment method, and logs.
- **Idea?** [Open a feature request](https://github.com/PicPeak/picpeak/issues/new?template=feature_request.md).

Please search existing issues first — someone may have already reported it.

## 🔒 Security

**Do not** open a public issue for security vulnerabilities. Follow the
[security policy](SECURITY.md): use
[GitHub Private Vulnerability Reporting](https://github.com/PicPeak/picpeak/security/advisories/new)
or email **info@picpeak.app**.

## ☕ Support the project

PicPeak is free and open source. If it saves you money, consider
[buying the maintainer a coffee](https://buymeacoffee.com/theluap).
